# homebrew-tap

Homebrew tap for [Suniye](https://github.com/kishanhitk/suniye) — open-source, local-first dictation for macOS.

## Install

```bash
brew install --cask kishanhitk/tap/suniye
```

Installs the latest release into `/Applications`. Suniye is self-signed (not
notarized), so the cask clears the Gatekeeper quarantine for you on install —
no manual `xattr` step. Updates are delivered in-app via Sparkle.

Uninstall (including downloaded models and app data):

```bash
brew uninstall --zap --cask suniye
```

## Maintenance

`Casks/suniye.rb` is generated by CI from
[`packaging/homebrew/suniye.rb.tmpl`](https://github.com/kishanhitk/suniye/blob/main/packaging/homebrew/suniye.rb.tmpl)
in the main repo on each stable release. Don't edit it here directly.
